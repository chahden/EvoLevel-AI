### 🎮 About the Project

**EvoLevel AI** is a Unity project exploring procedural level generation and adaptive gameplay.

The project focuses on creating grid-based levels, generating playable mazes, and exploring how Artificial Intelligence could analyze player performance to influence future level generation.

The goal is to experiment with the relationship between **procedural generation, player experience, and AI-driven adaptation.**

- 🗺️ **Grid-Based System** — Build levels using a structured grid.
- 🌊 **Maze Reveal Animation** — Reveal the generated maze through an expanding visual effect.
- 🎯 **Player & Goal System** — Spawn the player and goal dynamically.
- 🧠 **AI-Based Adaptation (In Development)** — Explore how AI can analyze player performance and suggest adjustments to future levels.
